## What is DAMI ? 

Dami is an educational AI project designed to help students on their learning journey.

Our goal is to build an intelligent educational assistant that can answer students' course questions using AI and Natural Language Processing (NLP) technologies and make learning easier and more engaging.

🔹 Areas of activity:

AI Natural Language Processing 
Development of educational assistants
Information Retrieval and Response Generation (RAG)
creating Edu agent for Iran school books 

🎯 Our vision:
To create a practical tool for Iranian students and help them learn better, deeper, and smarter.
